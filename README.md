# LegalEase – AI Legal Document Generator

LegalEase is an AI-powered legal document generator built with Python. Users can enter the document type, involved parties, terms and conditions, and effective date to generate a structured legal document.

## Features
- AI-based legal document generation using Gemini 1.5 Pro
- Document preview and inline editing
- Download as TXT, DOCX, and PDF
- FastAPI REST backend
- Streamlit frontend

## Tech Stack
- Python
- Streamlit (Frontend)
- FastAPI (Backend)
- Gemini 1.5 Pro (AI model)
- Pydantic (Validation)
- python-docx, fpdf2 (Document generation)
